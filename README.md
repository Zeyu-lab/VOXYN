# VOXYN

VOXYN is a lightweight voice and social platform prototype inspired by Discord.

The goal of this project is not to build a full Discord clone, but to create a small, practical full-stack web application that demonstrates frontend development, backend APIs, authentication, database integration, and real-world project structure.

## Overview

VOXYN is designed as a community-based platform where users can create accounts, join servers, enter voice rooms, use text chat, and interact with small social features.

This project is currently in early development. The first stage focuses on building a clean frontend structure, followed by backend APIs, Supabase integration, and additional real-time features.

## Planned Features

- User authentication
- User profiles
- Community servers
- Voice rooms
- Text chat
- Mini games
- Premium / payment system
- Supabase database integration
- RESTful backend APIs
- Cloud deployment
- Project documentation
